# AVT-Fabric

Project website for **AVT-Fabric: Active Visuo-Tactile Perception via Adaptive Evidence Selection for Efficient Robotic Fabric Comparison**.

Website: https://zhuochenn.github.io/AVT-project/

## Local preview

Run `python3 -m http.server 8000` and open http://localhost:8000. No build step or external dependencies are required.

## Deployment

GitHub Pages: deploy the `main` branch, `/ (root)`.
